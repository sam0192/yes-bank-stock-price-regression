# Yes Bank Stock Price Prediction using Regression

## 📌 Overview
This project focuses on predicting **Yes Bank stock prices** using historical stock market data.
Regression-based machine learning models are applied to understand price trends and relationships between stock features.

---

## 🎯 Problem Statement
Stock price prediction is a challenging task due to market volatility.
The objective of this project is to build a regression model that predicts the **closing price of Yes Bank stock**
using historical price-related features.

---

## 📊 Dataset Description
The dataset contains historical stock price information.

### Features
- `Open` – Opening stock price
- `High` – Highest price of the day
- `Low` – Lowest price of the day
- `Volume` – Trading volume

### Target Variable
- `Close` – Closing stock price

---

## 🛠️ Methodology
1. Data loading and inspection
2. Date handling and sorting
3. Exploratory Data Analysis (EDA)
4. Feature and target selection
5. Train-test split
6. Regression model training
7. Model evaluation

---

## 🤖 Models Used
- Linear Regression
- Ridge Regression
- Lasso Regression

---

## 📈 Evaluation Metrics
- R² Score
- Mean Squared Error (MSE)

---

## 🔍 Key Insights
- Strong correlation between open, high, low, and close prices
- Linear models perform well on historical price data
- Regularization helps stabilize predictions

---

## 🚀 Future Improvements
- Time series forecasting models (ARIMA, LSTM)
- Feature engineering using technical indicators
- Model deployment with live data

---

## 🧠 Learnings
- Regression on financial time-series data
- Market feature relationships
- Limitations of linear models in stock prediction
